# CLEO 4.4.4 Unofficial Patch

Неофициальный проект на базе **CLEO 4.4.4** для GTA San Andreas.

Это не официальный релиз CLEO. Здесь сохраняется исходное ядро CLEO 4.4.4 как совместимая основа, а дальнейшая работа направлена на исправление ошибок, модернизацию сборки, диагностику и развитие собственного API без отказа от совместимости со старыми CLEO-скриптами.

## Официальная база CLEO 4.4.4

- **Официальный репозиторий CLEO 4:** https://github.com/cleolibrary/CLEO4
- **Официальные релизы CLEO 4:** https://github.com/cleolibrary/CLEO4/releases
- **Релиз CLEO 4.4.4:** https://github.com/cleolibrary/CLEO4/releases/tag/v4.4.4
- **Официальный сайт:** https://cleo.li/

CLEO 4.4.4 — официальный исходный релиз, на базе которого развивается этот **Unofficial Patch**.

## Важное

- Оригинальная opcode-совместимость и формат старых скриптов не меняются без отдельной необходимости.
- Проект предназначен для **GTA San Andreas 1.0 US / Win32**.
- Название **CLEO 4.4.4 Unofficial Patch** используется для чёткого отличия этой разработки от официального CLEO.
- Оригинальные авторы CLEO 4.4.4 сохраняют свою атрибуцию.
- Официальные ссылки и происхождение исходного кода указаны в `UPSTREAM.md`.

## Статус

Проект находится в разработке. Сначала стабилизируется совместимое ядро CLEO 4.4.4, затем поверх него добавляются собственные современные возможности.
