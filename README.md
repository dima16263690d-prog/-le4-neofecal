# CLEO 4.4.4 Unofficial Patch

Неофициальный проект на базе **CLEO 4.4.4** для GTA San Andreas.

Это не официальный релиз CLEO. Здесь сохраняется исходное ядро CLEO 4.4.4 как совместимая основа, а дальнейшая работа направлена на исправление ошибок, модернизацию сборки, диагностику и развитие собственного API без отказа от совместимости со старыми CLEO-скриптами.

## Структура

- **[CLEO 4 4 4/](./CLEO%204%204%204/)** — исходный код проекта, SDK, плагины и Visual Studio solution.
- **[UPSTREAM.md](./CLEO%204%204%204/UPSTREAM.md)** — история и ссылки на предыдущих разработчиков и официальный проект CLEO 4.4.4.
- **[AUTHORS.md](./CLEO%204%204%204/AUTHORS.md)** — авторство, происхождение кода и участие AI-помощника в разработке.
- **[README проекта](./CLEO%204%204%204/README.md)** — техническая информация и направление разработки.

## Важное

- Оригинальные имена, opcode-совместимость и формат старых скриптов не меняются без отдельной необходимости.
- Проект предназначен для **GTA San Andreas 1.0 US / Win32**.
- Название **CLEO 4.4.4 Unofficial Patch** используется для отличия этой разработки от официального CLEO.
- Официальный проект и его исходная история указаны в `UPSTREAM.md`.

## Статус

Проект находится в разработке. Сначала стабилизируется совместимое ядро CLEO 4.4.4, затем поверх него добавляются собственные современные возможности.
