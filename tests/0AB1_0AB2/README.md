# 0AB1 / 0AB2 runtime test

Тест для CLEO 4.4.4 Unofficial Patch на GTA San Andreas 1.0 US.

## Что проверяет

- `0AB1: call_scm_func` с двумя входными параметрами;
- передачу `10` и `20` в локальные переменные функции;
- выполнение `005A: 0@ += 1@`;
- `0AB2: ret 1 0@`;
- возврат результата в caller `2@`;
- восстановление caller locals `0@=100` и `1@=7`.

## Сборка теста

1. Открыть `TEST_0AB1_0AB2.cs` в Sanny Builder.
2. Скомпилировать как CLEO `.cs`.
3. Поместить полученный `TEST_0AB1_0AB2.cs` в папку `cleo` / ModLoader.
4. Запустить GTA SA 1.0 US с собранным CLEO 4.4.4 Unofficial Patch.

## Ожидаемый результат

На экране:

```
0AB1/0AB2 PASS RESULT=30
```

Это означает:

```
10 + 20 = 30
caller 2@ = 30
caller 0@ = 100
caller 1@ = 7
```

Если появляется `FAIL`, сохранить `cleo_diagnostic.log` и основной CLEO log.

## Важно

Этот тест ничего не меняет в реализации `0AB1/0AB2`. Он только проверяет текущую реализацию.
Следующий этап после PASS: два return values, затем float, string, вложенные функции и проверка границы 32 параметров.
